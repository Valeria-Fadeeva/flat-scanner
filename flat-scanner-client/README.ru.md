# Flat Scanner Client

🌐 [English](README.md) | **Русский**

Высокопроизводительное нативное графическое приложение под Linux (x64), разработанное на Flutter для управления процессами оцифровки книг. Клиент выступает в роли управляющего фронтенда для асинхронного системного демона `flat-scanner-server` (Core Engine), взаимодействуя с ним по протоколу HTTP/JSON.

Реализует бесшовную нативную адаптацию интерфейса под **окружение KDE Plasma (Breeze)** за счет прямого низкоуровневого парсинга конфигурационного файла `kdeglobals` в динамическую цветовую схему Material 3 ColorScheme.

## Структура архитектуры

Архитектура проекта строго следует канонам разделения ответственности (**Clean Architecture**) и однонаправленного потока данных:

```
lib/
├── main.dart                     # Инициализация приложения, управление window_manager, MultiBlocProvider
├── data/                         # Слой данных (Взаимодействие с внешними источниками и ОС)
│   ├── api_service.dart          # HTTP-клиент низкого уровня для отправки команд системному серверу
│   ├── models.dart               # Строго типизированные DTO-модели (ScanProfile, ScanResponse, PageVertex)
│   └── theme_service.dart        # Системный парсер kdeglobals -> динамическая палитра Material 3
├── domain/                       # Слой бизнес-логики (Управление состояниями интерфейса)
│   └── scanner_bloc.dart         # Движок BLoC: преобразование событий сканирования в стейты UI
└── presentation/                 # Слой представления (Декларативный реактивный интерфейс)
└── scan_editor_page.dart         # Страница сканирования, выпадающий список профилей, полноэкранный режим
```

## Компиляция и развертывание в системе

### 1. Подготовка сборочного окружения
Для нативной сборки приложения в операционных системах Arch Linux или Melawy OS убедитесь в наличии следующих системных зависимостей:
```bash
sudo pacman -S gtk3 libnotify libuuid libxkbcommon flutter
```

### 2. Ручная сборка бинарного пакета
```bash
flutter pub get
flutter build linux --release
```
Результат компиляции и все сопутствующие библиотеки будут собраны в директории: `build/linux/x64/release/bundle/`

## Пакетная сборка и установка (Arch Linux / Melawy OS)

Корректное развертывание Flutter-приложений в Linux требует сохранения целостности структуры скомпилированной директории `bundle` для предотвращения ошибок линковщика динамических библиотек (`libflutter_linux_gtk.so`). Автоматизация сборки и установки осуществляется через нативный инструмент **PKGBUILD**.

Для автоматической сборки, проверки зависимостей и установки пакета в систему выполните:
```bash
makepkg -si
```

### Карта размещения компонентов приложения в ОС
* `/usr/lib/flat-scanner-client/` — Изолированный контейнер выполнения (исполняемый файл, `.so`-библиотеки, ресурсы `data/`, таблицы локализации `icudtl.dat`).
* `/usr/bin/flat-scanner-client` — Глобальный системный симлинк для запуска приложения из терминала или лаунчера.
* `/usr/share/applications/flat-scanner-client.desktop` — Файл интеграции приложения в графическое меню XDG.
